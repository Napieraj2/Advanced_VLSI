# Advanced_VLSI

Repository for Advanced VLSI course projects, reports, code, and results.

## Course Design Project (FIR Filter Design)

The attached course design project is FIR filter design and is due **March 24**.

Focus area discussed in class:
- Reduced-complexity parallel processing with parallelism factor L = 2 or L = 3.

### FIR Project Expectations
- Define FIR specifications and implementation goals.
- Develop a high-performance VLSI architecture.
- Include reduced-complexity parallel processing analysis for L = 2 and/or L = 3.
- Provide RTL implementation and verification evidence.
- Report area/speed/throughput trade-offs with clear analysis.

## Open-Ended Final Design Project

After completing the FIR project, begin planning the final project:
- Choose a data/signal processing function.
- Develop a high-performance VLSI architecture.
- Implement RTL and verify functionality/performance.

Selected project topic:
- Viterbi algorithm (high-performance VLSI architecture and RTL implementation).

## GitHub Submission Requirement (Both Projects)

For both the FIR design project and the open-ended final design project, include all work in this repository:
- Report
- Source code / RTL
- Results
- Analysis
